@inspirejs/prism

Syntax highlighting for your slides, powered by Prism

Language classes

Add a language-* class. Short names like lang-js work too. 

<code class="language-css">p { margin: 0 }</code>
p { margin: 0 }

One language per slide

Set it once, and every code block on the slide follows.

<section class="slide language-js">
	<pre><code>let x = 1;</code></pre>
</section>
let x = 1;

Prism plugins

Load as many Prism plugins as you like. Their styles come along.

<body
	data-prism-plugins="line-highlight, inline-color">
	<pre data-line="3">…</pre>
.slide {
	display: flex;
	gap: 1em;
	color: rebeccapurple;
}

Opting out

Leave any code block plain.

<pre class="prism-ignore">
	<code class="language-css">…</code>
</pre>
a { color: red }

Code added later

Code you add later gets highlighted too.

slide.insertAdjacentHTML("beforeend",
	`<pre><code class="lang-ts">${code}</code></pre>`);
Inspire.domchanged(slide);
